## 🚀 Featured Work

### 🛡️ Sentinel — API Failure Detection Platform

**Focus:** real-time monitoring + anomaly detection + AI-assisted root-cause analysis

Sentinel monitors API traffic, detects anomalies using a **Z-score sliding-window approach**, broadcasts live data through **WebSockets**, and uses **Groq/Llama** for root-cause analysis. The dashboard includes live KPIs, service dependency visualization, a health heatmap, incident tracking and streaming AI chat.

**Stack:** `Python` `FastAPI` `SQLite` `WebSockets` `SSE` `React` `Vite` `Recharts` `Canvas API` `Groq` `Llama`

🔗 **Repository:** https://github.com/Naseem-ux/sentinel

---

### 📚 EduFlow — Student Productivity Platform

**Focus:** full-stack web application + authentication + productivity workflows

EduFlow brings **notes, learning resources and tasks** into one workspace. The project uses a React frontend, Node/Express backend, MongoDB and JWT authentication.

**Stack:** `React` `Node.js` `Express.js` `MongoDB` `JWT`

🔗 **Repository:** https://github.com/Naseem-ux/EduFlow  
🌐 **Live project:** https://edu-flow-xi-five.vercel.app/
